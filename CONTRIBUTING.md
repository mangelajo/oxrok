# Contributing

## Ground rules

- Plain ASCII in code and docs. Terse technical English.
- `cargo fmt --all`, `cargo clippy --workspace --all-targets
  --all-features` with no warnings, `cargo nextest run --workspace
  --all-features` green. CI runs the same on Linux, macOS and Windows,
  with clippy from the current stable Rust and a build on the minimum
  supported version, 1.95.
- Every change that a user can see gets a line in `CHANGELOG.md`.
- No `unsafe` code. The one exception is `pydecode`, which crosses
  into Python; every block there says why it is sound.

## License

oxrok is GPL-3.0-or-later, like the sigrok code it ports
(`docs/LICENSING.md`). A file that corresponds to a sigrok file keeps
its `Counterpart in sigrok` header, generated by
`tools/attribution.py`.

## Adding a driver

`docs/DRIVER_PORTING.md` has the shape of a driver, the transports,
the testing approach and the pitfalls met so far. Every driver ships a
replay fixture so it is tested without the hardware, and an entry in
`docs/DEVICES.md` saying what has been verified on which device.

## Compatibility with sigrok-cli

Outputs are compared with sigrok-cli byte for byte after the header
line. When adding an output or changing one, capture the reference with
sigrok-cli and put it in the test next to the command that produced it.
`tools/diffcli.sh` runs the documented flows through both tools, with
`--hw` for the attached hardware.
